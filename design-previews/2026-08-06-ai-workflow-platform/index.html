D · 编辑式信报

Meridian · 编辑网格

方向说明

A · 极简精确 — 工具感与秩序，信息一次看全，像一个顺手的开发者终端。字体：Instrument Sans + 等宽数字。色彩：暖白底 + 墨黑 + 单一琥珀金。记忆点：克制的琥珀金状态点。适用：追求效率、清爽利落的用户。亮点：可混搭 A 的任务列表 + B 的卡片留白
B · 暖色高端（推荐） — 温暖纸感 + 琥珀金主色，延续你现有项目品牌，每天用不累。字体：Fraunces 衬线标题 + 无衬线正文。色彩：暖纸底 + 琥珀金 + 柔光阴影。记忆点：衬线数字和金色状态。适用：面向非技术卖家，亲切而有质感。推荐理由：工作台是高频工具，暖纸感亲和、延续琥珀金品牌记忆，四方向中最"舒服耐看"
C · 深色专业 — IDE 质感，高密度，像给重度用户的操作台。字体：Sora + JetBrains Mono。色彩：暖炭黑底 + 琥珀金重音（无霓虹）。记忆点：底部命令条。适用：喜欢深色、信息密集、开发者向。亮点：可混搭 C 的命令条 + B 的色彩
D · 编辑式信报 — 报纸般的编辑网格，非对称、分隔线而非卡片，克制又有个性。字体：系统衬线标题 + 等宽数字。色彩：纸底 + 低饱和琥珀/苔绿/雾蓝。记忆点：双线规则与日期栏。适用：追求独特气质、内容优先。亮点：可混搭 D 的编辑网格 + B 的配色
